# Repository and profession research — 24 October 2026

## Method and scope

Expanded the study catalogue across networking, architecture, testing, embedded systems, interface design, support, programming, games, data and AI. Repository selection favoured a concrete lesson, exercise or example over another overlapping link list. For each accepted resource, the source README, licensing terms and a representative learning example were read. The per-resource YAML records the precise source paths and limits.

Checks distinguish free reading from hardware, hosted compute, account requirements and commercial products. A public GitHub page alone does not establish an open-source licence or active maintenance. Mixed code/content licences and old version requirements are recorded. No third-party project was installed, executed or given access to user data. Exa was not available in this session; this research used primary sources directly.

## Considered but not added

- Rustlings, Go Tour, GDQuest and Docker getting-started material already had catalogue coverage; changing from a website URL to its source repository was not a reason to duplicate a resource.
- D2L was already catalogued; micrograd is covered by Zero to Hero, and fastbook by the fast.ai entry.
- Beej network programming and the Systems Approach textbook were already represented; related exercises were not counted again as a separate curriculum.
- Additional beginner Playwright examples would repeat the existing getting-started entry.
- The older Rust Embedded Discovery material identifies itself as deprecated; the micro:bit v2 edition was selected instead.
- The Art of Command Line substantially overlaps existing command-line resources; Windows administration material added a clearer gap. tldr was already present.
- Structurizr examples and the proposed Gophercises repository could not be verified at the tested paths. A failed lookup is not evidence that every related project is unavailable.
- WAI tutorial material was considered, but the licence could not be established from the source files checked. It was not added as a verified open-source resource. A related official guidance link remains clearly marked as unreviewed.
- A proposed Open Practice Library content repository was not verified; the checked official openpracticelibrary/openpracticelibrary repository was used instead.

## Profession taxonomy and curriculum guidance

The user-supplied role list informed six editorial groups. Variants are retained as aliases; repeated job titles are represented once, and seniority is not treated as a separate discipline. Individual profiles link to relevant areas and available introductory paths. A missing dedicated route is displayed as a gap. These descriptions are editorial, not endorsed role definitions from ACM, IEEE, SFIA or NIST.

No profession-specific curriculum was verified. Related sources are classified separately: academic curricula and directories, bodies of knowledge, competency frameworks, vendor-published educational curricula, certification objectives and professional guides. Sources that could not be read remain `link_only`; no absence claim is inferred.

The official ACM, IEEE Computer Society, SFIA and NIST websites were denied by the environment proxy. Guessed repository locations and third-party summaries were not used to manufacture primary verification. An additive network-domain update was saved in the environment configuration draft; this does not itself change runtime access or publish the environment.

Read sources include the CNCF repository and CKA/CKS objective documents, Cisco course examples, and Microsoft AI, Data Science and IoT beginner curricula. Provider courses and exam objectives do not by themselves define the entire profession.

## Validation and limitations

The repository checks validate source data, references and generated pages. Unit tests exercise repository selection, profession metadata, navigation and malformed input. This is a content and navigation review; execution or compatibility of every external exercise remains untested.

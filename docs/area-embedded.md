## Selected repositories

- [Microsoft IoT for Beginners](https://github.com/microsoft/IoT-For-Beginners): Microsoft's 24-lesson project-based IoT curriculum covering device code, sensors, actuators, MQTT messaging, cloud connectivity and telemetry, with physical or virtual hardware options. (beginner; Free)
- [Rust Embedded Discovery - micro:bit v2](https://github.com/rust-embedded/discovery-mb2): Project-based book introducing microcontrollers through Rust on a BBC micro:bit v2, with setup, debugging and hardware exercises such as LED roulette. (intermediate; Free)

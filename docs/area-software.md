# Programming and software engineering

_Learn languages, Git, the command line and how to build software well._

81 resources. [Home](../README.md) / [Catalogue](catalogue.md)

## Not sure where to start?

- [Start from zero: your first steps](path-0-fundamentals.md): Start from zero, write your first programs and choose a direction.
  Before you start: Basic file and browser skills; no previous programming or terminal experience is required.
- [First project: web development](path-web-development.md): Build a small, accessible website with HTML, CSS and JavaScript.
  Before you start: Basic file and folder skills, a browser and a text editor; Git is only needed for optional publishing.

For a longer learning recipe, [choose a profession curriculum](curricula.md).

The catalogue below is a reference shelf. You do not need to use every resource. [Read the access and level labels](catalogue.md#read-resource-labels).

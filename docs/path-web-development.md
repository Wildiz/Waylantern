# Path: web development

Web developers build pages and applications people use in a browser. This route is for beginners who want to make their first small website, starting with the visible page rather than a server or framework. You need basic file and folder skills, a browser and a text editor; no previous web programming is required. Basic Git from Path 0 helps with the optional publishing step. Keep the same small project throughout, such as a study-resource page, and use invented example content instead of personal information.

[Back to the start](../README.md)

If a step assumes programming or terminal skills you have not learned, use the relevant parts of [Path 0](path-0-fundamentals.md) first. Work through one small step at a time; you do not need to finish every linked course.

## Step 1: Make one useful HTML page

Use the Learn web development section, starting with HTML and your first website. Create a study-resource page with a descriptive title, a heading, a short introduction, a list of links and an image with useful alternative text. Open your own file in a browser and check that its links work.

- [MDN Web Docs](https://developer.mozilla.org/) (Free): Mozilla-run documentation hub for HTML, CSS, JavaScript, Web APIs and HTTP, with reference pages, guides and a Learn web development section.

**Advance when:** Your page opens locally, has a clear heading structure and meaningful link text, and you can explain what each HTML element adds.

## Step 2: Make the page readable on a small screen

Follow the introductory CSS lessons and style the same page. Give the text a comfortable width, space the sections and let the layout adapt to narrow windows. Use the browser's developer tools to try a change before saving it. Check the page using the keyboard as well as the mouse.

- [MDN Web Docs](https://developer.mozilla.org/) (Free): Mozilla-run documentation hub for HTML, CSS, JavaScript, Web APIs and HTTP, with reference pages, guides and a Learn web development section.

**Advance when:** The page remains readable in a narrow window without horizontal scrolling, and you can reach each link with the keyboard and see which link has focus.

## Step 3: Add one small interaction

Read the basics of variables, functions and conditions, then the browser lessons on DOM elements and events. Add a button that shows or hides extra study notes on your page. Give it a clear label, test both states and use the browser console to investigate mistakes. You do not need a framework.

- [The Modern JavaScript Tutorial (javascript.info)](https://javascript.info/) (Free): Open-source tutorial that teaches the JavaScript language from the basics to OOP, then browser topics such as the DOM and events, with tasks at the end of articles.

**Advance when:** The button works with mouse and keyboard, the page is still useful before it is clicked, and you can explain how the event changes the page.

## Step 4: Review and optionally publish your website

Check your page's links, layout and interaction once more, then write a short README explaining how to open it. If you want to share it, follow the GitHub Pages quickstart in a separate practice repository. Public-repository hosting is available on GitHub Free; publish only files and content you intend anyone to see. Publishing is optional, and a local working site is a valid result.

- [GitHub Pages](https://pages.github.com/) (Free): Static website hosting from a GitHub repository, with one user or organization site per account and unlimited project sites, suitable for a beginner portfolio.

**Advance when:** Someone else can follow your README to open the site, or visit the optional published version, and you can describe one improvement based on their feedback.

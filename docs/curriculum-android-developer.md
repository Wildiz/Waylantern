# Learning curriculum: Android Developer

Build a small Android application with Kotlin, Compose and persistent state.

[Home](../README.md) / [Curricula](curricula.md) / [Software, interfaces and embedded systems](professions-software.md#roles-in-this-group)

**Target profile:** [Android Developer](professions-software.md#android-developer)

**Starting point:** Start with the basics

**Type:** Waylantern editorial learning recipe. Related official sources are listed separately below.

## Before you start

- Basic computer skills
- A computer supporting Android development tools

**What you will produce:** An Android task app checked through invalid input, rotation and restart.

**Resource coverage:** 4 of 4 stages have no recorded resource gap. Read the marked gaps before planning your study.

Resource access labels refer to the material or software. Open a resource's details to check prerequisites, hardware, APIs and other running costs before using it.

## Your sequence

1. [Learn Kotlin values](#stage-1)
2. [Build a Compose screen](#stage-2)
3. [Preserve application state](#stage-3)
4. [Deliver the Android mini-app](#stage-4)

<a id="stage-1"></a>
## 1. Learn Kotlin values

**Learn:**

- Variables and functions
- Conditions
- Collections

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) — beginner in this topic; free access. [Details](area-software.md#resource-android-basics-compose).

**Practise:** Complete introductory Kotlin exercises and represent a task as structured data.

**Advance when:** Explain a function that adds a task and rejects an empty title.

After the checkpoint, [continue to stage 2](#stage-2).

<a id="stage-2"></a>
## 2. Build a Compose screen

**Learn:**

- Composable functions
- State updates
- Labels and inputs

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) — beginner in this topic; free access. [Details](area-software.md#resource-android-basics-compose).

**Practise:** Create an add-task screen with a labelled field and visible list.

**Advance when:** Add two tasks and explain why a state change updates the displayed list.

After the checkpoint, [continue to stage 3](#stage-3).

<a id="stage-3"></a>
## 3. Preserve application state

**Learn:**

- Lifecycle events
- Local storage
- Error handling

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) — beginner in this topic; free access. [Details](area-software.md#resource-android-basics-compose).

**Practise:** Use the course persistence material and test a configuration change.

**Advance when:** Distinguish state surviving rotation from state surviving a complete app restart.

After the checkpoint, [continue to stage 4](#stage-4).

<a id="stage-4"></a>
## 4. Deliver the Android mini-app

**Learn:**

- UI checks
- Accessible controls
- Reproducible build

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [Android Basics with Compose](https://developer.android.com/courses/android-basics-compose/course) — beginner in this topic; free access. [Details](area-software.md#resource-android-basics-compose).

**Practise:** Deliver the task app with an emulator configuration and empty-input and restoration checks.

**Advance when:** Rebuild and demonstrate task creation, restart recovery and clear control labels.

## After this recipe

Continue with networking and permissions; emulator checks do not replace supported physical-device testing.

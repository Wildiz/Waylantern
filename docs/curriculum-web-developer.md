# Learning curriculum: Web Developer

Build a small content-oriented website with clear navigation and maintenance checks.

[Home](../README.md) / [Curricula](curricula.md) / [Software, interfaces and embedded systems](professions-software.md#roles-in-this-group)

**Target profile:** [Web Developer](professions-software.md#web-developer)

**Starting point:** Start with the basics

**Type:** Waylantern editorial learning recipe. Related official sources are listed separately below.

## Before you start

- Basic file skills
- A browser and text editor

**What you will produce:** A multi-page information site with working links and a reproducible local setup.

**Resource coverage:** 4 of 4 stages have no recorded resource gap. Read the marked gaps before planning your study.

Resource access labels refer to the material or software. Open a resource's details to check prerequisites, hardware, APIs and other running costs before using it.

## Your sequence

1. [Structure useful content](#stage-1)
2. [Make the site readable](#stage-2)
3. [Enhance without hiding content](#stage-3)
4. [Deliver the information-site mini-project](#stage-4)

<a id="stage-1"></a>
## 1. Structure useful content

**Learn:**

- Semantic HTML
- Page titles
- Link destinations

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [MDN Web Docs](https://developer.mozilla.org/) — all in this topic; free access. [Details](area-web.md#resource-mdn-web-docs).

**Practise:** Create two study-resource pages with distinct titles and descriptive cross-links.

**Advance when:** A reader identifies each page purpose and navigates between them without ambiguous links.

After the checkpoint, [continue to stage 2](#stage-2).

<a id="stage-2"></a>
## 2. Make the site readable

**Learn:**

- CSS layout
- Responsive images
- Keyboard focus

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [web.dev Learn](https://web.dev/learn) — beginner in this topic; free access. [Details](area-web.md#resource-web-dev-learn).

**Practise:** Style narrow and wide layouts and add useful image alternative text.

**Advance when:** Avoid horizontal overflow and reach every link by keyboard.

After the checkpoint, [continue to stage 3](#stage-3).

<a id="stage-3"></a>
## 3. Enhance without hiding content

**Learn:**

- DOM events
- Basic validation
- Failure fallback

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [The Modern JavaScript Tutorial (javascript.info)](https://javascript.info/) — beginner in this topic; free access. [Details](area-web.md#resource-javascript-info).

**Practise:** Add a resource filter while preserving the full list when JavaScript is unavailable.

**Advance when:** Demonstrate filtering and verify that all content remains reachable without the enhancement.

After the checkpoint, [continue to stage 4](#stage-4).

<a id="stage-4"></a>
## 4. Deliver the information-site mini-project

**Learn:**

- Static hosting
- Link checks
- Content maintenance

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [GitHub Pages](https://pages.github.com/) — beginner in this topic; free access. [Details](area-web.md#resource-github-pages).
- [MDN Web Docs](https://developer.mozilla.org/) — all in this topic; free access. [Details](area-web.md#resource-mdn-web-docs).

**Practise:** Deliver local instructions and optionally publish only intended public content in a separate practice repository.

**Advance when:** Reproduce a fresh local run, verify internal links and update content without breaking navigation.

## After this recipe

Choose frontend application or backend study according to needed features; optional publication is not a claim of production readiness.

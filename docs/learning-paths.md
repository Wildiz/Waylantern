# Try an area: first-project guides

Choose a small project to discover whether you enjoy an area. These guides have a few steps and checkpoints. For a longer sequence toward a profession, [choose a curriculum](curricula.md).

[Home](../README.md) · [Understand the professions](professions.md) · [Resource catalogue](catalogue.md)

## No previous programming needed to begin

| Guide | First project | What you need first |
|---|---|---|
| [Start from zero: your first steps](path-0-fundamentals.md) | Start from zero, write your first programs and choose a direction. | Basic file and browser skills; no previous programming or terminal experience is required. |
| [First project: cybersecurity](path-cybersecurity.md) | Learn security fundamentals through authorized labs and clear reports. | Basic file skills and access to an SSH client; Python 3 is used for the local HTTP exercise. |
| [First project: data analysis](path-data-analysis.md) | Turn a small dataset into checked answers and a clear chart. | A browser is enough to begin SQL; learn basic Python variables, lists, loops and functions before Step 3. |
| [First project: interface and product design](path-interface-design.md) | Observe one user task, sketch an interface and test a small clickable prototype. | Basic browser and file skills; no coding experience is required to sketch and prototype an interface. |
| [First project: IT support and help desk](path-it-support.md) | Practise basic Linux diagnosis and document a simulated support case in a ticket lab. | Basic computer skills and access to a disposable Linux practice environment; no programming experience is required. |
| [First project: web development](path-web-development.md) | Build a small, accessible website with HTML, CSS and JavaScript. | Basic file and folder skills, a browser and a text editor; Git is only needed for optional publishing. |
## Learn the named foundations first

| Guide | First project | What you need first |
|---|---|---|
| [First project: AI and machine learning](path-ai-machine-learning.md) | Train and evaluate a small machine-learning model on tutorial data. | Basic Python functions and lists, plus familiarity with tables, averages and simple algebra. |
| [First project: embedded systems](path-embedded-systems.md) | Choose Arduino or Raspberry Pi Pico and build a small, explainable LED firmware project. | Basic programming concepts, a compatible Arduino or Raspberry Pi Pico board, its cable and the matching toolchain. |
| [First project: networking](path-networking.md) | Understand connections, build a small network and diagnose a broken link. | Basic file management and terminal commands; programming experience is not required. |
| [First project: software testing and QA](path-software-testing.md) | Learn to describe expected behavior, automate checks and investigate failures in one small project. | Basic programming and terminal skills; the Playwright option also needs JavaScript or TypeScript and basic HTML. |

| Guide | First project | What you need first |

<a id="resource-govuk-design-system"></a>
<details><summary>GOV.UK Design System: requirements and source notes</summary>

**Topic level:** intermediate. Read the requirements below before choosing it.

**Languages recorded:** en

**Useful for:**

- Component guidance explains when to use a pattern and how to word its controls
- Includes concrete HTML examples and links to the reusable GOV.UK Frontend code

**Requirements, costs and limitations:**

- Written for UK government services; adapt the reasoning rather than copying its branding
- A reference rather than a full design course; implementing examples needs web development knowledge

**Source checked:** 2026-10-24 (github-repo).

Read alphagov/govuk-design-system main README.md, LICENSE and src/components/button/index.md via raw.githubusercontent.com. The button guide explains action labels, when to use a button and avoiding multiple primary actions, with HTML/Nunjucks examples. The root repository LICENSE is MIT; this does not establish permission to reuse government branding or every linked asset. Reading the source guidance is free; running the documentation site needs Git, Node.js and installation. English source checked; hosted site, implementation and translations were not tested.

**Study format:** self-directed. **Focus-friendly rating:** unknown (editorial judgment).

</details>

<a id="resource-open-practice-library"></a>
<details><summary>Open Practice Library: requirements and source notes</summary>

**Topic level:** intermediate. Read the requirements below before choosing it.

**Languages recorded:** en

**Useful for:**

- Practice descriptions make collaborative discovery activities concrete
- The empathy-mapping example identifies participants, duration and ways to collect observations

**Requirements, costs and limitations:**

- Some activities need a facilitator and other participants; it is not a solo course
- Assumptions from a workshop are not a substitute for evidence from users

**Source checked:** 2026-10-24 (github-repo).

Read openpracticelibrary/openpracticelibrary master README.md, LICENSE and src/pages/practice/empathy-mapping.md via raw.githubusercontent.com. README describes collaborative practices and iterative delivery; the concrete practice lists participants, a suggested duration and sources of user insight, and attributes empathy mapping to Dave Gray of XPLANE. The root repository LICENSE is Apache-2.0; linked third-party resources retain their own terms. Free refers to reading the repository, not workshop facilitation services or infrastructure. English checked; hosted site and practice outcomes were not tested.

**Study format:** self-directed. **Focus-friendly rating:** unknown (editorial judgment).

<details><summary>Penpot: requirements and source notes</summary>

**Topic level:** beginner. Read the requirements below before choosing it.

**Languages recorded:** en

**Useful for:**

- MPL-2.0 source code with a self-hosting option
- Official README links a learning centre and UI design course
- Connects interface design with familiar web standards

**Requirements, costs and limitations:**

- The application is a practice tool, not a complete design curriculum
- Self-hosting requires installation and server resources; enterprise features are a separate paid plan

**Source checked:** 2026-10-24 (github-repo).

Read penpot/penpot develop README.md and LICENSE via raw.githubusercontent.com. The README describes interface design, prototyping, components, design tokens, SVG/CSS standards, browser and self-hosted use, and links official learning resources. LICENSE is MPL-2.0. The README explicitly identifies Penpot Enterprise as paid for cloud and self-hosted deployments; freemium reflects that distinction, not a verified hosted price or quota. English README checked; learning course contents, translations and application operation were not tested.

**Study format:** self-directed. **Focus-friendly rating:** unknown (editorial judgment).

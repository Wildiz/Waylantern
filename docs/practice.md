## Pros and cons

<details><summary>Show pros and cons for each entry</summary>

**A Tour of Go**

- Good: Run code in the browser
- Good: Official
- Watch out: Brief; not a full course

**Advent of Code**

- Good: Language-agnostic puzzles
- Good: Past years available for practice
- Good: No CS background needed
- Watch out: Puzzle text may not be redistributed
- Watch out: Calendar format is shorter in recent years (fewer days per event per FAQ)

**AtCoder**

- Good: Beginner-oriented AtCoder Beginner Contests held every week (schedule visible on the home page)
- Good: English interface and English problem statements
- Good: Practice contest for first-time users
- Watch out: Pricing is not stated on the pages read
- Watch out: Contest-oriented rather than a guided course

**Cisco Packet Tracer**

- Good: Free download, no hardware needed
- Good: Visualises how networks work
- Watch out: Requires a free Cisco Networking Academy account to download
- Watch out: Simulator only: some commands and features differ from real devices

**Codecademy**

- Good: Free Basic plan
- Good: Guided paths from beginner level
- Good: In-browser lessons
- Watch out: Skill, career and certification paths are not available on Basic (pricing page)
- Watch out: Free content is limited
- Watch out: Prices may change

**CodeCrafters**

- Good: Real-world systems projects
- Good: Automated stage tests
- Watch out: Free tier has limited content access; full content needs a paid membership
- Watch out: Aimed at experienced engineers

**Codeforces**

- Good: Frequent rated contests
- Good: Huge archive of problems with tags and difficulty ratings
- Good: Active community with editorials and blog posts
- Watch out: Contest problems are hard for beginners
- Watch out: Not a structured curriculum
- Watch out: Official site sits behind bot protection (could not be read automatically)

**Codewars**

- Good: Small exercises with instant test feedback
- Good: 55+ languages
- Good: See other users' solutions after solving
- Watch out: Quality varies since kata are user-authored
- Watch out: Optional Codewars Red subscription adds enhanced statistics, ad-free experience, peer comparison, beta features and a badge; ads are shown without it (inferred from the Red feature list)

**Codility Lessons**

- Good: Ordered lessons from basic iteration to dynamic programming
- Good: Practice style matches Codility's hiring tests
- Watch out: Primarily interview preparation
- Watch out: Site states the browser may be unsupported on some setups
- Watch out: Free vs paid status not stated on the page

**CSES Problem Set**

- Good: Well-organised by topic
- Good: Automatic judging
- Watch out: No explanations; assumes competitive-programming knowledge

**CyberDefenders**

- Good: Zero setup, labs run in the browser
- Good: Focused on defensive security and SOC skills
- Watch out: CyberRange premium labs cost $25 per month; certifications from $599
- Watch out: Which labs are free was not confirmed

**Exercism**

- Good: Small exercises with automated test feedback
- Good: 85 language tracks
- Good: Optional human mentoring
- Watch out: Exercises assume you already know basic programming (beginners are pointed to the separate Jiki platform)
- Watch out: Spanish covers the site interface; exercise content is English (per the language selector)

**Flexbox Froggy**

- Good: Tiny levels with immediate visual feedback
- Good: No setup or account
- Good: Many interface languages
- Watch out: Covers only flexbox
- Watch out: Does not teach HTML or when to use flexbox in real layouts

**freeCodeCamp**

- Good: Interactive in the browser
- Good: Certifications with projects and exam
- Good: Open source
- Watch out: Many learners stall without external structure (anecdotal)

**Frontend Mentor**

- Good: Real-world project briefs
- Good: Free members can use challenges and get one AI review per month
- Watch out: Pro plan needed for a review on every submission and extra content

**GitHub Skills: Introduction to Git**

- Good: No previous Git or version control experience required
- Good: A small project gives the commands a concrete purpose
- Watch out: Basic command-line and VS Code familiarity recommended
- Watch out: Requires a GitHub account; private exercise repositories consume Actions minutes

**GitHub Skills: Introduction to GitHub**

- Good: No previous GitHub experience required
- Good: Four steps with a concrete file to create
- Watch out: Requires a GitHub account and copying the exercise into a repository
- Watch out: Private exercise repositories consume GitHub Actions minutes

**Grid Garden**

- Good: Short levels with immediate visual feedback
- Good: No setup or account
- Good: Many interface languages
- Watch out: Covers only CSS grid
- Watch out: Not a replacement for learning HTML/CSS broadly

**HackerRank**

- Good: Interview Prep Kit with mock tests and mock interviews (per official help center)
- Good: Practice in many languages and domains such as algorithms and SQL
- Watch out: Home page is aimed at employers hiring developers, which can confuse learners
- Watch out: Free vs paid split for candidates not confirmed from a primary source
- Watch out: Practice pages need JavaScript and a login

**iximiuz Labs**

- Good: Real servers in the browser
- Good: Free forever Basic plan
- Watch out: Basic: 1 playground and 1 hour per day, only some content free
- Watch out: Bundle is $10 per month billed $120 per year

**Kaggle Learn**

- Good: Runs in the browser with no setup
- Good: Exercises are auto-checked
- Good: Courses are short and self-contained
- Watch out: Shallow depth compared with full courses
- Watch out: Needs a free Kaggle account for notebooks

**Kattis Problem Archive**

- Good: Problems carry numeric difficulty scores
- Good: Supports many programming languages
- Good: Problems are linked from USACO Guide lessons
- Watch out: Requires registering an account to submit
- Watch out: Terse problem statements, no tutorials
- Watch out: Pricing not stated on the pages read

**Killercoda**

- Good: No setup: ready environments in the browser
- Good: Free scenarios usable without limit
- Watch out: Free sessions limited to 1 hour
- Watch out: CKA/CKAD/CKS courses are paid

**KodeKloud**

- Good: Hands-on labs in the browser, no card needed to start
- Good: Free 100 Days of Cloud challenge listed
- Watch out: Full course and lab library needs a paid subscription
- Watch out: Exact free limits and plan prices not confirmed (pricing page needs JavaScript)

**Learn Git Branching**

- Good: Visual feedback after each command
- Good: Short levels
- Good: No install
- Watch out: Covers Git concepts only

**LeetCode**

- Good: Very large problem library with in-browser editor and automatic judging
- Good: Weekly contests and a big community of solutions and discussions
- Good: Free tier is widely used for interview prep (per third-party guides)
- Watch out: Paid Premium plan unlocks company-tagged questions and some problems
- Watch out: Interview-drill focus, not a structured course
- Watch out: Official site sits behind bot protection (could not be read automatically)

**NeetCode**

- Good: Curated, ordered problem lists
- Good: Video explanations (author's YouTube channel)
- Watch out: Some problems and features are marked Pro in the site's own code and sit behind a paid NeetCode Pro plan; exact free/paid split and current prices not captured
- Watch out: Interview-prep focus, not general learning

**OverTheWire Wargames**

- Good: Bandit is a gentle intro to the Linux shell
- Good: No installation beyond an SSH client
- Watch out: Hints are minimal by design
- Watch out: Community-run, little hand-holding

**OWASP Juice Shop**

- Good: Score board tracks challenge progress
- Good: Open source (MIT) with a companion guide
- Watch out: Must be installed and run yourself
- Watch out: Only attack your own local instance; never real systems without permission

**OWASP WebGoat**

- Good: Lesson-based, so more guided than a pure challenge app
- Good: Runs locally; Docker image available
- Watch out: Needs local setup and the machine is vulnerable while it runs
- Watch out: Java-focused examples

**picoCTF (CyLab Security Academy)**

- Good: Beginner-friendly CTF challenges
- Good: Run by a university
- Watch out: Platform is mid-migration (picoctf.com announced as coming soon)

**PostgreSQL Exercises**

- Good: Learn by doing with immediate feedback in the browser
- Good: Single simple dataset, so no setup
- Watch out: Exercises only, designed to accompany a book or the Postgres docs
- Watch out: Limited explanation of theory

**Project Euler**

- Good: Combines math and programming
- Good: Language-agnostic
- Watch out: Needs math comfort
- Watch out: Not a tutorial: no teaching material

**Rustlings**

- Good: Tiny exercises with immediate compiler feedback
- Good: Official Rust project, MIT license
- Watch out: Needs local Rust install

**SQLBolt**

- Good: 18 short lessons with instant checks
- Good: No setup
- Watch out: Beginner-level only

**SQLZoo**

- Good: Many practice queries
- Good: No setup
- Watch out: Dated interface

## Pros and cons

<details><summary>Show pros and cons for each entry</summary>

**Anki**

- Good: Desktop app is free for Windows, macOS and Linux
- Good: AnkiWeb sync is free
- Good: Built-in FSRS scheduler (opt-in in deck options)
- Good: Large add-on and shared-deck ecosystem
- Good: Short daily review sessions with immediate feedback
- Watch out: iOS app (AnkiMobile) is paid: US$24.99 on the US App Store at check time
- Watch out: Steep learning curve for card templates and settings
- Watch out: Value depends on writing good cards yourself; copying other people's decks teaches less

**AnkiDroid**

- Good: Free and open source (GPL-3.0)
- Good: Works offline; syncs with desktop Anki via AnkiWeb
- Good: Active project
- Watch out: Android only (iOS users must buy AnkiMobile)
- Watch out: Developed by volunteers; fewer features than desktop for card editing

**ChatGPT study mode**

- Good: Search summaries of OpenAI's help center say it is available on Free, Plus, Pro and other plans on web, iOS and Android
- Good: Aims at active learning with questions and quizzes
- Watch out: Official OpenAI pages returned 403 to automated fetches, so plan availability is not directly confirmed
- Watch out: Release notes say it is powered by system instructions and may behave inconsistently or make mistakes
- Watch out: Not available in Projects, GPTs or Temporary Chats (per search summary of help article)
- Watch out: Can be switched off to get direct answers

**Claude learning mode**

- Good: Designed to guide reasoning rather than just answer (Anthropic's education page)
- Good: Claude Code 'Learning' style leaves small pieces of code for you to write and adds explanatory insights
- Watch out: Chat-app learning mode is described by Anthropic as part of Claude for Education (institution-level; claude.com/pricing lists 'Academic research and learning mode' under the higher-education plan) and availability for individual or Free-plan users is not confirmed
- Watch out: Claude Code is not included in the Free plan (claude.com/pricing shows Pro and Max only)
- Watch out: Like all LLMs it can be wrong; verify against documentation
- Watch out: You can always ask for the answer directly, so it only helps if you stay disciplined

**Cold Turkey Blocker**

- Good: Hard-to-bypass blocking with locking options (Pro)
- Good: Free version includes timed website blocks and statistics
- Good: Pro is a one-time lifetime purchase, not a subscription
- Good: 20% student discount on request
- Watch out: Windows and macOS only; Linux, ChromeOS, Android and iOS are not supported
- Watch out: Application blocking and scheduling need Pro

**CS50.ai (CS50 Duck)**

- Good: Tuned to CS50 course material
- Good: Explicitly allowed by CS50's academic-honesty policy (unlike general chatbots)
- Good: Built to help rather than write the answer (course notes)
- Watch out: Requires logging in; whether it is free to all learners was not confirmed
- Watch out: CS50 itself warns it is an experimental AI and not to trust it blindly
- Watch out: Aimed at CS50 course work

**Datasette**

- Good: Open-source under Apache-2.0
- Good: Explore database tables and query data through a web interface
- Good: README links examples, documentation and the browser-based Datasette Lite variant
- Watch out: Local server installation requires Python 3.11 or higher according to the README
- Watch out: Publishing on external hosting providers may incur costs
- Watch out: A self-directed data tool rather than a guided SQL course

**DB Browser for SQLite**

- Good: Open-source under a choice of MPL-2.0 or GPL-3.0 or later
- Good: Browse tables and records through a spreadsheet-like interface
- Good: Run SQL queries and inspect the generated SQL command log
- Watch out: Requires local installation
- Watch out: Works with SQLite databases rather than every database engine
- Watch out: Not intended to replace a spreadsheet application

**DeepTutor**

- Good: Apache-2.0 and very active (~42k stars, release v1.6.15 on 2026-10-19)
- Good: Works with local models via Ollama or LM Studio, or your own API key
- Good: README in 12 languages including Spanish
- Watch out: You must run it yourself and supply a model provider (API costs may apply)
- Watch out: Setup is more technical than a hosted tutor
- Watch out: Hallucination risk depends on the model; always verify answers
- Watch out: Fast-moving project; features and quality vary

**draw.io (diagrams.net)**

- Good: Free forever and no sign-up per the official site
- Good: Apache-2.0 licensed source code
- Good: Saves to local disk, Google Drive, GitHub and others
- Good: Desktop apps and VS Code extension
- Watch out: More effort per diagram than text-based tools like Mermaid
- Watch out: UI-language coverage not verified

**Excalidraw**

- Good: Free, MIT-licensed (per project README)
- Good: Hand-drawn style makes quick explanation sketches easy
- Watch out: Not a formal diagram tool (no auto-layout)
- Watch out: A paid Excalidraw+ exists ($6 per user per month
- Watch out: 14-day trial) for cloud-saved scenes
- Watch out: comments and teams; the free editor stays free

**FLOWN**

- Good: 30-day free trial without payment details
- Good: Free account keeps access to free sessions on Fridays
- Good: Sessions with facilitators and shared intentions
- Watch out: Most sessions need a paid monthly, yearly or lifetime membership after the trial
- Watch out: Effectiveness of body doubling for ADHD is not firmly established in research

**Focus Timer (GNOME Pomodoro)**

- Good: GPL-3.0
- Good: Actively maintained
- Watch out: GNOME/Linux only
- Watch out: Timer only; no task tracking

**Focusmate**

- Good: Free plan with no credit card
- Good: Session starts and ends with a stated goal, which gives a clear start and finish
- Good: Sessions can be booked at many times of day
- Watch out: Free plan is capped at 3 sessions per week; unlimited sessions need Plus
- Watch out: Requires being on camera with a stranger, which some people find uncomfortable
- Watch out: Evidence that body doubling helps ADHD specifically is limited and mixed; the vendor cites general social-facilitation research

**Forest**

- Good: Simple gamified loop for short focus intervals
- Good: Core focus experience is free
- Good: Browser extension for desktop
- Watch out: Plus subscription adds further features and price varies by store and region
- Watch out: Gamification can lose its pull over time (user reports, not verified)

**Freedom**

- Good: Blocks across multiple devices at once
- Good: Locked mode (Premium) prevents quitting a session
- Good: Free tier available
- Watch out: Scheduling, recurring sessions and locked mode need Premium
- Watch out: Free tier session limits were not confirmed

**FSRS (Free Spaced Repetition Scheduler)**

- Good: MIT license
- Good: Optimizes intervals from your own review history to hit a chosen retention target
- Good: Built into current Anki (Deck Options > FSRS)
- Watch out: Every Anki client you sync with must support FSRS (warned in the Anki manual)
- Watch out: The repo is the legacy Anki add-on/optimizer project; for current Anki use the built-in option

**Gemini Guided Learning**

- Good: Uses LearnLM-based tuning built with educators (per Google's blog)
- Good: Multimodal explanations and quizzes
- Good: Educators can share it through Google Classroom
- Watch out: Plan requirements and pricing are not stated in the announcement post
- Watch out: Free promotional student plans have been time-limited and region-specific
- Watch out: Can still be wrong; verify facts

**Gemini Notebook (NotebookLM)**

- Good: Answers are grounded in the sources you upload and cite them
- Good: Generates flashcards, quizzes, mind maps and overviews from your own material
- Good: Standard tier is free with a Google account
- Watch out: Can still misread or oversimplify sources; verify against the originals
- Watch out: Passive consumption (audio overviews, summaries) can replace real study
- Watch out: Free tier has usage limits (e.g. notebooks and sources per notebook)
- Watch out: Product has been renamed; the site currently brands itself 'Gemini Notebook'

**GitHub Pages**

- Good: Free hosting for public repositories on GitHub Free
- Good: Step-by-step quickstart on the landing page
- Good: Publishes straight from a repo
- Watch out: Static sites only (HTML, CSS, JavaScript)
- Watch out: Private-repository publishing needs a paid GitHub plan

**GLPI**

- Good: GPL-3.0 software with official administrator and installation documentation
- Good: Combines helpdesk workflows, asset tracking and a knowledge base in one application
- Watch out: A working service-desk application rather than a guided IT support course
- Watch out: Self-hosting needs a web server, PHP with required extensions and MariaDB or MySQL
- Watch out: Use synthetic tickets and assets for practice rather than real personal or workplace information

**Goblin Tools**

- Good: Web tools are free, stated to stay ad-free and paywall-free
- Good: Magic ToDo gives a quick way to break a vague task into steps
- Watch out: Output is AI-generated and can be wrong; the site says treat it as guesswork
- Watch out: Mobile apps are paid (low price) and some advanced features need Goblin Tools Pro

**Google Colab**

- Good: No setup; works in the browser with a Google account
- Good: Free tier includes GPUs and TPUs per the official FAQ
- Good: Good for ML and data science courses
- Watch out: Free resources are not guaranteed and not unlimited; usage limits fluctuate and expensive GPUs are heavily restricted on the free tier
- Watch out: Free runtimes may be terminated, and SSH, remote desktops and some web UIs are disallowed on the free tier
- Watch out: Paid tiers (Pro, compute units) exist; their prices were not checked

**Habitica**

- Good: Open source (GPL v3 code)
- Good: Game mechanics reward small completed tasks
- Good: Web and mobile apps
- Watch out: Rewards-and-penalties loop does not suit everyone
- Watch out: Optional paid Subscription (cosmetic and convenience perks such as Gold-purchasable Gems) and paid Group Plans exist; Habitica itself has paused outside code contributions since Aug 2026 per its README

**Joplin**

- Good: Free and open source
- Good: Windows, macOS, Linux, Android and iOS
- Good: Web clipper for Chrome and Firefox
- Good: Plugins and themes
- Watch out: Less oriented to linked-note workflows than Obsidian or Logseq
- Watch out: Joplin Cloud is a separate paid service (plans from 2.99 EUR/month billed monthly or 28.69 EUR/year for 2 GB
- Watch out: 14-day free trial; Dropbox/OneDrive/Nextcloud sync can be used instead)

**Khanmigo**

- Good: Designed not to hand out answers directly
- Good: Built into Khan Academy exercises and videos
- Good: Free for teachers; learner plan costs US$4/month
- Watch out: Learner access requires living in the United States with a U.S. billing address; under-18s need a parent or guardian to sign up (khanmigo.ai/learners)
- Watch out: Learner plan is paid (US$4/month or US$44/year per the learners page, excluding sales tax)
- Watch out: Uses a GPT-4-class model, so it can still make mistakes
- Watch out: Coverage is school and intro-level, not advanced IT

**LeechBlock NG**

- Good: Free
- Good: Up to 30 block sets with different times and days
- Good: Options page can be password or access-code protected
- Good: Works on Linux, unlike some desktop blockers
- Watch out: Browser-only: does not block other applications or other browsers
- Watch out: Easy to disable if you control the browser settings

**Logseq**

- Good: Free and open source (AGPL-3.0)
- Good: Outliner format suits daily journaling and linked notes
- Good: Works from local files
- Watch out: The newer database-based version is in beta and the README warns data loss is possible
- Watch out: Mobile apps are less mature (README: DB-version iOS app alpha, Android coming soon)
- Watch out: Learning curve for the outliner workflow

**Manim Community**

- Good: Open-source software under the MIT license
- Good: Create mathematical visualizations by writing and modifying Python code
- Good: Documentation includes installation instructions and examples
- Watch out: Local use requires Python and additional dependencies
- Watch out: The community edition and the original 3Blue1Brown version have different installation instructions
- Watch out: A tool for creating explanations rather than a structured mathematics course

**marimo**

- Good: Open-source under Apache-2.0
- Good: Dependent cells update when their inputs change
- Good: Includes an introductory tutorial and links to examples
- Watch out: Assumes familiarity with Python for writing notebooks
- Watch out: Reactive execution can rerun expensive computations unless configured otherwise
- Watch out: External AI providers or hosting can have separate costs and requirements

**Mermaid**

- Good: MIT license
- Good: Diagrams-as-code that live in version control
- Watch out: Layout is automatic and limited
- Watch out: The project now points to mermaid.ai for a platform around the library; paid tiers exist there (Basic free with limited diagrams
- Watch out: Plus $10 and Premium $20 per user per month billed annually)

**Mochi Cards**

- Good: Free tier with unlimited offline usage
- Good: Markdown cards and templates, FSRS mentioned in the docs
- Watch out: Sync across devices needs Pro at US$5/month
- Watch out: Smaller ecosystem than Anki

**Netlify (Free plan)**

- Good: Free plan with Git-based deploys and custom domains
- Good: Deploy previews for every change
- Watch out: Free plan is limited to a monthly credit allowance (300 credits per month on the page read)
- Watch out: Pricing changes over time; recheck before relying on limits

**Notion (free plan and Education Plan)**

- Good: Free plan for individuals
- Good: Free Education Plan for students and teachers with an institutional email (one-member workspace)
- Good: Free plan for eligible student organisations
- Good: Templates for student planners and trackers
- Watch out: Closed source and cloud-based; limited offline use
- Watch out: Free plan only includes a trial of Notion AI
- Watch out: Can become an elaborate organisation project instead of studying

**Obsidian**

- Good: Free for personal, commercial and non-profit use, no account needed
- Good: Notes are plain Markdown files stored locally
- Good: 40% discount on Sync/Publish for students and faculty (per pricing page)
- Good: Plugin catalogue is linked from the official site (not itemised here)
- Watch out: Official Sync costs US$4/month (billed yearly) or US$5/month
- Watch out: Easy to over-tinker with plugins and themes instead of studying (widely reported in the community)

**Orange Data Mining**

- Good: Open-source under GPL-3.0 or later
- Good: Visual workflows provide a way to explore data without writing code
- Good: Windows and macOS installers are linked from the official README
- Watch out: Local installation is required
- Watch out: Linux installation requires preparing an environment; pip installation may need a compiler
- Watch out: Individual add-ons and their requirements were not checked

**Penpot**

- Good: MPL-2.0 source code with a self-hosting option
- Good: Official README links a learning centre and UI design course
- Good: Connects interface design with familiar web standards
- Watch out: The application is a practice tool, not a complete design curriculum
- Watch out: Self-hosting requires installation and server resources; enterprise features are a separate paid plan

**Pomofocus**

- Good: No install needed
- Good: Customizable focus and break lengths, alarm and background sounds
- Watch out: Reports and integrations are premium features
- Watch out: Premium price not captured

**Pomotroid**

- Good: MIT license
- Good: Configurable work and break lengths
- Good: Session statistics and many themes
- Watch out: Timer only; no task management or blocking
- Watch out: Interface language other than English not confirmed

**Project Jupyter**

- Good: Free, open-source and the standard notebook tool for data work
- Good: Offers a try-in-browser option (per the site)
- Good: Runs many languages through kernels
- Watch out: Local use needs installation
- Watch out: Notebooks can become messy for large codebases

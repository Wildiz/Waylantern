# Computer networks

_Protocols, packet analysis, network simulation and how computers communicate._

11 resources. [Back to the start](../README.md)

## Selected repositories

- [Computer Networks: A Systems Approach](https://github.com/SystemsApproach/book): Open textbook by Larry Peterson and Bruce Davie covering network foundations, internetworking, scaling, end-to-end protocols, congestion, security and applications. (intermediate; Free)
- [Mininet](https://github.com/mininet/mininet): Linux network emulator with Python examples for building virtual hosts, switches and links and experimenting with connectivity, bandwidth, delay and packet loss on one machine. (intermediate; Free)

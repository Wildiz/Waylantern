## Courses and books

| Name | Cost | Level | Guided? | Focus-friendly | Languages | What it is |
|---|---|---|---|---|---|---|
| [Introduction to Linux (LFS101, Linux Foundation)](https://training.linuxfoundation.org/training/introduction-to-linux/) | Free | beginner | guided | - | en, es | Free Linux Foundation course on working with Linux through the graphical interface and command line across the major distribution families, ending with shell scripting and local security basics. |
| [Linux Upskill Challenge](https://github.com/livialima/linuxupskillchallenge) | Free | beginner | guided | - | en | A sequenced hands-on Linux administration course covering server access, command-line navigation, packages, services, logs, networking, users and permissions. |
| [Professor Messer (CompTIA Network+ and Security+ videos)](https://www.professormesser.com/security-plus/sy0-701/sy0-701-video/sy0-701-comptia-security-plus-course/) | Free | beginner | guided | - | en | Free video training courses for the CompTIA Security+ (SY0-701), Network+ (N10-009) and A+ exams, with optional paid course notes and practice exams. |
| [The Linux Command Line (William Shotts)](https://linuxcommand.org/tlcl.php) | Free | beginner | guided | - | en, es | A 596-page book that teaches the Linux command line and shell scripting from scratch, free to download as a PDF under a Creative Commons license. |

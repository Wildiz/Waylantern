# Learning curriculum: Software Engineer

Turn a small requirement into tested, maintainable software.

[Home](../README.md) / [Curricula](curricula.md) / [Software, interfaces and embedded systems](professions-software.md#roles-in-this-group)

**Target profile:** [Software Engineer](professions-software.md#software-engineer)

**Starting point:** Start with the basics

**Type:** Waylantern editorial learning recipe. Related official sources are listed separately below.

## Before you start

- Basic file and folder skills
- A computer that can run Python

**What you will produce:** A command-line study tracker with saved data, tests and reproducible instructions.

**Resource coverage:** 4 of 4 stages have no recorded resource gap. Read the marked gaps before planning your study.

Resource access labels refer to the material or software. Open a resource's details to check prerequisites, hardware, APIs and other running costs before using it.

## Your sequence

1. [Write a small program](#stage-1)
2. [Preserve structured records](#stage-2)
3. [Check changes systematically](#stage-3)
4. [Deliver the tracker mini-project](#stage-4)

<a id="stage-1"></a>
## 1. Write a small program

**Learn:**

- Variables and types
- Conditions and loops
- Functions

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/) — beginner in this topic; free access. [Details](area-cs.md#resource-cs50-python).

**Practise:** Record a study session and calculate its total minutes.

**Advance when:** Run three inputs and explain how the program computes each total.

After the checkpoint, [continue to stage 2](#stage-2).

<a id="stage-2"></a>
## 2. Preserve structured records

**Learn:**

- Lists and dictionaries
- File input and output
- Validation

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [The Python Tutorial (official)](https://docs.python.org/3/tutorial/) — beginner in this topic; free access. [Details](area-software.md#resource-python-tutorial).

**Practise:** Save sessions in JSON and reject negative durations and empty subjects.

**Advance when:** Restart the program and recover the saved sessions while invalid records remain rejected.

After the checkpoint, [continue to stage 3](#stage-3).

<a id="stage-3"></a>
## 3. Check changes systematically

**Learn:**

- Unit tests
- Exceptions
- Version control

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [pytest - Get Started](https://github.com/pytest-dev/pytest/blob/main/doc/en/getting-started.rst) — beginner in this topic; free access. [Details](area-testing.md#resource-pytest-getting-started).
- [Pro Git](https://git-scm.com/book/en/v2) — beginner in this topic; free access. [Details](area-software.md#resource-pro-git).

**Practise:** Separate calculations from input/output and test empty, valid and invalid records.

**Advance when:** Demonstrate a regression test failing before a fix and passing afterward.

After the checkpoint, [continue to stage 4](#stage-4).

<a id="stage-4"></a>
## 4. Deliver the tracker mini-project

**Learn:**

- Module boundaries
- Documentation
- Regression checks

**Study resources** — consult the sections needed for this task; the resources may teach complementary skills:

- [The Python Tutorial (official)](https://docs.python.org/3/tutorial/) — beginner in this topic; free access. [Details](area-software.md#resource-python-tutorial).
- [pytest - Get Started](https://github.com/pytest-dev/pytest/blob/main/doc/en/getting-started.rst) — beginner in this topic; free access. [Details](area-testing.md#resource-pytest-getting-started).

**Practise:** Deliver sample data, setup instructions and a documented limitation with the tracker.

**Advance when:** Follow the README in a fresh folder and reproduce the sample totals and test results.

## After this recipe

Study data structures and software design next; Senior and Principal describe responsibilities and experience, not separate beginner courses.

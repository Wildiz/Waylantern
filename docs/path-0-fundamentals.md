# Path 0: fundamentals

A general, no-deadline order for someone starting IT from zero. Do one step at a time. Move on when you can do the "advance when" check, not when a calendar says so.

[Back to the start](../README.md)

## Helpers: use them all along

Two habits that make every step easier. Start them early and keep them all along. Free content has plenty of material and little structure, so decide how you will stay focused and how you will remember things.

- [Focusmate](https://www.focusmate.com/) (Free + paid extras): Virtual coworking service that pairs you on video with another member for a silent, timed work session in which you each state your goal.
- [Anki](https://apps.ankiweb.net/) (Free + paid extras): Open-source spaced-repetition flashcard program with add-ons, media support and optional free AnkiWeb sync; desktop and Android are free, the iOS app is paid.

## Step 1: Learn the basics of computing and write your first code

Pick one. CS50x is a university-style intro to computer science, and Automate the Boring Stuff is a gentler Python book if you prefer something lighter.

- [CS50x - Harvard's Introduction to Computer Science](https://cs50.harvard.edu/x/) (Free): Harvard's free introductory CS course covering Scratch, C, algorithms, memory, data structures, Python, SQL, HTML/CSS/JavaScript and Flask, ending in a final project.
- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) (Free): Beginner Python book on practical automation (files, spreadsheets, web scraping, email) that is free to read online under a Creative Commons license.

**Advance when:** You can write a small program that takes input, makes decisions and repeats something, and explain what it does.

## Step 2: Practice with small exercises

Instant feedback on small problems builds the habit of writing code every day.

- [Exercism](https://exercism.org/) (Free): Code-practice platform with exercises in 85 programming languages, automated tests and optional volunteer mentoring.

**Advance when:** You solve easy exercises without looking up the solution.

## Step 3: Learn the terminal and Git

Every software, data and AI job uses the command line and version control.

- [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/) (Free): MIT course teaching practical tooling: the command line, a text editor, version control, packaging and shipping code, code quality and AI-assisted coding workflows, with lecture videos and notes.

**Advance when:** You can move around in a terminal, and create and push a Git repository.

## Step 4: See the big picture and choose a direction

Now that you know the basics, a roadmap shows what exists (web, data, AI...). Change direction freely, nothing you learned so far is wasted.

- [roadmap.sh](https://roadmap.sh/) (Free + paid extras): Interactive role and skill roadmaps (Frontend, Backend, DevOps, Data Analyst, AI Engineer, AI Agents, Prompt Engineering and more) with linked resources per topic.

**Advance when:** You can name the area you want to try next and the first thing to learn there.

## Step 5: Follow a full path (optional)

If you want a complete ordered curriculum, pick one of these and follow it.

- [freeCodeCamp](https://www.freecodecamp.org/) (Free): Free self-paced curriculum with interactive coding challenges, projects and certifications (web, JavaScript, Python, databases, APIs, machine learning).
- [The Odin Project](https://www.theodinproject.com/) (Free): Open-source full-stack web development curriculum (Foundations, JavaScript, Node, React, Ruby on Rails, databases) with projects and an active Discord.
- [Open Source Society University - Computer Science](https://github.com/ossu/computer-science) (Free): Free self-paced undergraduate-level CS curriculum built from existing online courses (Intro, Core, Advanced, Final project).

**Advance when:** You finished a project of your own, not just a course.

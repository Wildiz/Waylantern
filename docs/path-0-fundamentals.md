# Path 0: fundamentals

A general, no-deadline order for someone starting IT from zero. Do one step at a time. Move on when you can do the "advance when" check, not when a calendar says so. When a step offers alternatives, choose one main resource; you do not need to finish every linked course. At the end of each study session, save what you made and write down the next small action. If a check is too hard, revisit just that topic and try a smaller example before moving on.

## Optional helpers for focus and memory

Two optional helpers for focus and memory. Try one only if it solves a problem you have; setting up apps is not a prerequisite for learning. A timer and a notebook are enough to start. Use short sessions and write down questions to revisit instead of opening a new course every time you get stuck.

- [Focusmate](https://www.focusmate.com/) (Free + paid extras): Virtual coworking service that pairs you on video with another member for a silent, timed work session in which you each state your goal.
- [Anki](https://apps.ankiweb.net/) (Free + paid extras): Open-source spaced-repetition flashcard program with add-ons, media support and optional free AnkiWeb sync; desktop and Android are free, the iOS app is paid.

## Step 1: Learn the basics of computing and write your first code

Pick one. Choose CS50x for a university-style introduction to computer science, or Automate the Boring Stuff for practical Python automation. Start with the opening lesson, follow its setup instructions and run the examples yourself. Change one small thing in an example and explain the result before continuing.

- [CS50x - Harvard's Introduction to Computer Science](https://cs50.harvard.edu/x/) (Free): Harvard's free introductory CS course covering Scratch, C, algorithms, memory, data structures, Python, SQL, HTML/CSS/JavaScript and Flask, ending in a final project.
- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) (Free): Beginner Python book on practical automation (files, spreadsheets, web scraping, email) that is free to read online under a Creative Commons license.

**Advance when:** You can write a small program that takes input, makes decisions and repeats something, and explain what it does.

## Step 2: Practice with small exercises

Choose exercises in the same language you started in Step 1. Try a small problem, run the tests and use the feedback to revise your answer. If you need a hint, use it, then solve a similar problem on your own. You can keep practising alongside the later steps.

- [Exercism](https://exercism.org/) (Free): Code-practice platform with exercises in 85 programming languages, automated tests and optional volunteer mentoring.

**Advance when:** You can solve a few easy exercises, explain your answers and use a failing test to find and fix a mistake.

## Step 3: Learn the terminal and Git

Start with the shell lessons in The Missing Semester to learn how to navigate files and run commands; you do not need the entire course yet. Then use Introduction to Git for local commits and branches. Introduction to GitHub is an optional next exercise for sharing changes through a pull request.

Git tracks changes; GitHub hosts repositories and supports collaboration. The GitHub Skills exercises need an account, and private exercise repositories consume Actions minutes. Keep passwords and API keys out of practice repositories.

- [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/) (Free): MIT course teaching practical tooling: the command line, a text editor, version control, packaging and shipping code, code quality and AI-assisted coding workflows, with lecture videos and notes.
- [GitHub Skills: Introduction to Git](https://github.com/skills/introduction-to-git) (Free): Guided command-line Git exercise covering repository creation, commits, history, comparisons and branches while working on a sample game.
- [GitHub Skills: Introduction to GitHub](https://github.com/skills/introduction-to-github) (Free): Guided beginner exercise that uses a profile README to teach GitHub repositories, branches, commits and pull requests.

**Advance when:** You can find a project in the terminal, create a Git repository, commit a file and inspect its history. If you use GitHub, you can also explain what a branch and pull request do.

## Step 4: See the big picture and choose a direction

Use a roadmap to compare directions such as web development, data and AI. Treat it as a map, not a checklist to finish. Pick one area and a tiny project you would like to make, then identify just the next skill needed for that project. You can change direction later.

- [roadmap.sh](https://roadmap.sh/) (Free + paid extras): Interactive role and skill roadmaps (Frontend, Backend, DevOps, Data Analyst, AI Engineer, AI Agents, Prompt Engineering and more) with linked resources per topic.

**Advance when:** You can name the area you want to try next and the first thing to learn there.

## Step 5: Follow a full path (optional)

This step is optional. For a web-focused path, compare freeCodeCamp and The Odin Project; for broader computer science, look at OSSU and its prerequisites. Choose one curriculum that fits your goal instead of studying all three in parallel. If you already have a project in mind, use the relevant area page to fill gaps as you build it.

- [freeCodeCamp](https://www.freecodecamp.org/) (Free): Free self-paced curriculum with interactive coding challenges, projects and certifications (web, JavaScript, Python, databases, APIs, machine learning).
- [The Odin Project](https://www.theodinproject.com/) (Free): Open-source full-stack web development curriculum (Foundations, JavaScript, Node, React, Ruby on Rails, databases) with projects and an active Discord.
- [Open Source Society University - Computer Science](https://github.com/ossu/computer-science) (Free): Free self-paced undergraduate-level CS curriculum built from existing online courses (Intro, Core, Advanced, Final project).

**Advance when:** You have built a small project of your own, can explain how it works and can name one improvement you would make next. This is a checkpoint, not a requirement to finish an entire curriculum.
